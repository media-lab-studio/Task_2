# Stellar Burgers: тесты API

Учебный проект для проверки регистрации, входа, изменения профиля и заказов.

## Запуск

Нужны JDK 21 или 22, Maven и доступ к учебному стенду. В корне проекта выполните:

```shell
mvn clean test
mvn allure:serve
```

Первая команда запускает тесты из `src/test/java/burgers`, вторая открывает отчёт по этому запуску. Чтобы посмотреть сохранённый отчёт без Maven и подключения к стенду, скачайте `allure-report/index.html` и откройте в браузере.

Каждый тест использует собственные данные. Аккаунты удаляются после теста; для заказов в API нет ручки удаления. Идентификаторы ингредиентов берутся из каталога стенда при запуске.

При запуске `mvn test` (в том числе из окна Maven в IDEA) в консоли видны начало и результат каждого шага `@Step`, а также метод, путь и статус HTTP-запросов. Заголовки и тела запросов в лог не выводятся.
